The band is a physical module, not a setting. Array, filters, power amplifier and the array calibration table all live in it, and the module reports its own identity to the processing body over the dock. Changing band means changing the module.

These three values together confirm the unit is tracking the intended trunk and not a neighbouring system on the same band.

Fallback channel

The Texas Statewide Interoperability Channel Plan designates a direct/talkaround channel per band. The Orb monitors it alongside the trunk, which is how it hears units that could not get on the system at all.

The list is confined to the fitted band module. A UHF or VHF talkaround channel is not offered here because the receiver cannot reach it — the front-end filters and the array are cut for one band, and both live in the module.

Array and heading integrity Not built
Array manifold calibration — loaded from the band module
Each module carries its own measured phase-and-amplitude table. Without it the three elements cannot be compared and no bearing exists.
Magnetometer gradient check
Two dedicated magnetometers at the outboard lid corners. Earth's field is uniform across the lid, so any difference between them is a local disturbance — a vehicle, a fence, a light pole. The hardware is selected; the validation is not done.
Deployment orientation and levelling
A bearing is only as good as the heading it is measured against.

Hardware design §5.3 and §5.8. Hardware selected, validation open. Nothing on this page reads these sensors.

Orb collective Not built
Peers discovered on the ARC Edge network
Orbs find each other and merge what they each heard. There is no master — every unit runs the same reducer over the same observations and reaches the same answer.
Shared COP layer publication
The unit with the lowest identifier among visible peers publishes, which needs no election traffic and no protocol.
System-namespaced unit identity
Unit IDs are unique only within one P25 system, and an interoperability channel is cross-agency by definition. This is already a defect for a single unit, not just for a collective.
