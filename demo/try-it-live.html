Type anything an officer might say over the radio and the same model that labelled every transmission in the demo will classify it, right now, over the network.

This page is separate from the demo on purpose. The two-tab presentation replays classifications that were generated ahead of time and cached, so it needs no network at all. This page is the one place that makes a live call — so if the venue's wifi drops, this is all that breaks.
What is actually happening when you press Classify
  1. The browser posts your text to /api/classify on the local server started by serve.py.
  2. That server reads the Anthropic API key from .env and calls the model. The key never reaches the browser — putting it in client-side JavaScript would ship the secret to anyone who opens developer tools or later reads the repository.
  3. The prompt, the model and the output schema are the exact ones in classifier.py — the same file the cached demo labels were generated with. There is no second, easier prompt for the live demo.
  4. The response comes back as structured JSON, which is what lets the detection engine treat it as data instead of parsing prose.
